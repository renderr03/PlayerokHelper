# Общий Telegram-бот для нескольких магазинов

Это план следующего этапа. В 0.5.8 работает самостоятельная установка для одного магазина; общий сервис с регистрацией продавцов ещё не реализован.

## Пользовательский сценарий

Продавец открывает ссылку на общего бота, нажимает «Подключить магазин», вводит токен Playerok и ключ поставщика. Сервер автоматически проверяет доступ, показывает имя магазина и баланс. Продавец выбирает товары, сроки и предел расходов. Установка VPS и ввод серверных команд не нужны.

## Изоляция перед публичным запуском

- Telegram ID владельца связывается с отдельным store_id; доступ проверяется на каждом сообщении, callback и фоновом действии. Значения из callback не считаются подтверждением владельца.
- У каждого магазина отдельная база, каталог, состояние форм, очередь, лимиты расходов, резервные копии и ключ шифрования. Секреты не попадают в общую диагностику. Первый вариант — изолированный рабочий процесс на магазин с общим интерфейсом и управляющим сервисом.
- Подключение одного и того же Playerok-аккаунта к разным владельцам требует явной процедуры переноса. Дублирующих обработчиков заказов быть не должно.
- Обновления выполняются централизованно, по одному магазину с проверкой запуска и откатом. Обновление нельзя запускать произвольным кодом из пользовательского callback.
- Лимиты запросов, блокировки закупок и идемпотентность сохраняются в границах магазина. Сбой или лимит поставщика одного продавца не останавливает остальных.
- Доступны отключение магазина, отзыв ключей, выгрузка и удаление своих данных с учётом незавершённых операций. Операторская поддержка не получает права покупать или возвращать средства без соответствующего доступа.

## Порядок внедрения

1. Вынести выбор контекста магазина и проверку владельца перед обработчиками Telegram; сохранить текущий движок внутри изолированного рабочего процесса.
2. Добавить регистрацию, хранилище ключей и запуск/остановку рабочих процессов; предусмотреть лимиты ресурсов, резервирование и мониторинг.
3. Проверить минимум два магазина одновременно: чужие кнопки/заказы/чаты/ключи недоступны, обновление и сбой одного не затрагивают второй.
4. Провести закрытую бету на собственных магазинах. После приёмки открыть приглашения другим продавцам и определить условия поддержки и оплаты.

Упрощённое подключение 0.5.8 — первый шаг. Оно само по себе не делает текущий процесс безопасным общим сервисом; подключать чужие магазины к одной существующей базе нельзя.
