# PlayerokHelper v0.4.1 — оформление обновлений

Бот показывал Markdown из GitHub как обычный текст: заголовки с `##`, выделение с `**` и обрезанный посреди пункта список. Теперь уведомление и меню `/version` используют краткое представление для Telegram.

- До шести целых строк, суммарно не более 650 символов описания.
- Без маркеров заголовков, выделения, обратных кавычек и синтаксиса ссылок Markdown.
- Блоки кода с командами установки и служебные комментарии исключаются из превью.
- Полный отчёт доступен по ссылке; кнопка обновления сохраняется.
- Старое описание, сохранённое в базе, также форматируется при открытии меню после установки v0.4.1.

Короткий текст опубликован и для релиза v0.4.0, поэтому пользователи старого бота получат читаемое описание при следующей проверке GitHub. Сообщения, уже отправленные в Telegram, не меняются.

## Как обновиться

Откройте `/version` → **«Проверить сейчас»** → **«Обновить бота»**. Если ручная проверка выполнялась меньше минуты назад, дождитесь окончания этого интервала. Стандартная установка с systemd поддерживает переход с v0.3.0 и v0.4.0. Системный помощник, протокол обновления и схема базы не меняются.

Все [возможности v0.4.0](v0.4.0.md) сохраняются. Изменение относится только к представлению описания обновлений.

Проверки: 146 тестов, линтер, форматирование и shell-синтаксис проходят локально. Покрыты уведомление из ответа GitHub, ограничения длины без обрезания строк, удаление разметки и блоков кода, а также отображение старого кэша в Telegram-меню. Тесты используют подменённые API; реальные сообщения пользователям при разработке не отправлялись.
