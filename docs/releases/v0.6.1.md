# PlayerokHelper 0.6.1 · VingBoost

27 ноября 2026 года.

Добавлена отдельная преднастройка VingBoost для существующего SMM-модуля. Поставщик доступен через кнопки Telegram, provider-setup и шаблоны настроек. Рабочий адрес — https://vingboost.com/api/v2; старый домен vingboost.ru перенаправляет на него.

После сохранения ключа баланс и каталог проверяются автоматически, без закупок. При ошибке проверки ключ остаётся зашифрованным, поставщик выключен. Для запуска нужны выбранная услуга, лимиты и включение поставщика.

Учтены отличия протокола: простые нативные типы услуг, Awaiting как ожидание выполнения, order вместо orders для отмены, проверка подтверждений cancel/refill. Специальные и неизвестные типы исключаются, частичные и ошибочные заказы передаются на сверку. Оплаченные запросы не получают автоматических транспортных повторов. Остальные SMM-панели сохраняют прежний формат.

Проверены публичная справка сайта и анонимный ответ API без ключа. Авторизованная живая покупка не проводилась. Тесты используют подменённого поставщика и проверяют весь путь от ключа до выполнения заказа, цену, баланс, типы, статусы, формат отмены, подтверждения и сохранность ключа. Полный pytest: 383 теста прошли. Ruff, форматирование, проверка shell и сборка/установка wheel 0.6.1 прошли. Публикация стабильного релиза выполняется после успешного GitHub CI на Python 3.11/3.12.

Схема базы, шифрование, финансовые лимиты, service.py, updater_worker.py и протокол 1 не меняются. Ранее добавленные ключи и лоты сохраняются.

Обновление: «Версия и обновления → Проверить сейчас → Обновить бота». Затем «Плагины → SMM-услуги → Подключить поставщика → VingBoost».
