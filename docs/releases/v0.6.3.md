# PlayerokHelper 0.6.3 · окна и навигация

28 ноября 2026 года.

Перестроена структура экранов по предоставленному пользователем примеру и исправлен возврат из формы правил автоответчика.

## Что изменилось

- Вертикальное главное меню из семи разделов; добавление аккаунта показывается до подключения.
- Профиль содержит повседневную работу с чатами, заказами, покупателями и событиями. Управление — подключения, статус, пауза, обновления и резервная копия.
- Автонастройки разделены по задачам. Включение события и его текст находятся в одной карточке. Параметры ежедневного отчёта собраны на отдельном экране.
- На обычном экране одна кнопка «Назад», в форме один ряд «Назад / Отменить». Удаляются повторяющиеся действия и лишние переходы в общее меню инструментов.
- Отмена возвращает в исходный раздел. Назад без истории формы использует сохранённого родителя; промежуточного экрана с выбором случайного направления больше нет.
- Перезапуск сохраняет адрес текущей панели и родителя формы. Старые меню продолжают редактировать актуальную панель и сохраняют уведомления отдельно. В метаданных нет содержимого форм и секретов.
- Неверный ввод не накапливает лишние шаги истории, сохранение обычной настройки возвращает к её карточке.

## Проверки

Добавлены регрессии последовательности из видео, неверного ввода, отмены, всех типов обратного перехода после перезапуска, старого меню после уведомления, карточек событий и отсутствия повторяющихся кнопок. Существующий автоматический обход интерфейса проверяет единственность callback и нижней кнопки возврата.

435 тестов прошли. Ruff, форматирование, shell и сборка/установка wheel 0.6.3 прошли. Стабильный релиз публикуется после успешного GitHub CI на Python 3.11/3.12. Внешние API подменяются; реальные покупки, возвраты, отправки покупателям и развёртывание на VPS не выполнялись.

Схема базы, финансовые состояния и протокол помощника обновления 1 не меняются. Добавлены только настройки метаданных навигации в существующей таблице settings.
