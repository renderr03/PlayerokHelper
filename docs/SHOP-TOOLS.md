# Инструменты магазина · 0.6.0

Обновление рассчитано на один магазин на вашем VPS. Данные, ключ шифрования и прежние настройки сохраняются. Все основные действия доступны кнопками; обязательного теста со снятием товара нет.

## Каталоги

«Привязать лот» загружает собственные товары Playerok. Доступны страницы и поиск по загруженным названиям, повторная загрузка и запасной ввод ссылки. Загружается до 2000 товаров за один запрос каталога; сетевой таймаут ограничен. Чужие товары исключаются, выбранный ID повторно проверяется по владельцу.

После выбора типа аренды KOSell и названия открывается каталог игр. Продавец явно выбирает соответствие; совпадение названий не является разрешением на автоматическую закупку. Кнопки сроков учитывают диапазон выбранной игры. Для склада пропускаются бессмысленные ID игры, часы и лимит KOSell. После сохранения инструкции магазин использует существующий механизм обработки оплаченных заказов.

## Шаблоны

В карточке лота нажмите «Сохранить шаблон», задайте название. Сохраняются тип, часы, предел закупки и инструкция; для Stars/SMM — количество, предел в валюте и тип поставщика. Токен, складские реквизиты, заказы, получатели, чужие аккаунты, платное поднятие, ручная пауза и конкретный поставщик назначения не копируются.

Выберите совместимые лоты, откройте предпросмотр и подтвердите применение. Подтверждение одноразовое, действует пять минут и отменяется при переходе в другое окно. Конкурентно изменённые или несовместимые лоты пропускаются; результат приходит TXT-файлом. Рабочие счётчики мониторинга не делают настройки устаревшими.

Импорт/экспорт — JSON до 128 КБ, строгий формат без посторонних полей. Ограничение: 100 шаблонов, до 200 выбранных лотов за применение. Перед передачей файла другому человеку проверьте свободный текст инструкции: бот исключает технические секретные поля, но не может определить любой секрет, самостоятельно написанный продавцом в инструкции. Шаблон можно удалить кнопкой.

## Сценарии общения

Конструктор: название → фраза → состояние заказа → рабочее/нерабочее время → ответ, инструкция или передача продавцу → приоритет → задержка → ограничение повторов. Готовое правило сохраняется выключенным; включение — отдельной кнопкой. Есть изменение, выключение и удаление.

На сообщение выбирается одно включённое правило с максимальным приоритетом; при равенстве — более длинная фраза. Подтверждение оплаты берётся только из заказа, а не из текста покупателя. Нет действий покупки, выдачи пароля, возврата или исполнения кода. Обычные пользовательские команды обслуживаются существующими обработчиками.

Задержка 0–3600 секунд, приоритет 0–1000, повтор 1–86400 секунд. Очередь сохраняется; сообщение имеет срок актуальности. Изменение, удаление и выключение правила отменяет его ожидающие ответы. Уже отправленный или неопределённый ответ не повторяется вслепую. До 100 правил. Предпросмотр доступен без заказа или из карточки покупателя по данным конкретного заказа; он ничего не отправляет.

## Покупатели

В рабочем окне чата доступна карточка покупателя. Показываются история этого магазина, подтверждённые покупки, аренды, приватная заметка и метка. Заметка шифруется, не включается в сообщения покупателям. Метки: постоянный клиент, нужна помощь, ручной ответ. Метки доступны как фильтры покупателей и чатов. Ручной ответ передаёт новые сообщения продавцу без автоматического общения; это не отменяет финансовые обязательства по уже оплаченным заказам.

В карточке также виден последний сработавший сценарий. Споры и негативные обращения не вызывают автоматического возврата средств.

## Расчёт цены

Калькулятор читает текущую закупку KOSell или стоимость свободной складской позиции. Если данных нет, можно явно ввести ручную оценку. Укажите желаемую маржу от продажной цены, известную комиссию и нижнюю/верхнюю границы. Рекомендация округляется вверх до копейки; недостижимая в пределах цена не предлагается. Котировка действует для формы пять минут.

Цена на площадке не изменяется. Автоматическое изменение цен не включено: наш адаптер записи цены не прошёл живую приёмку. Неизвестные затраты и будущие изменения цены поставщика не гарантируются расчётом.

## Календарь и графики

Календарь на сегодня/неделю показывает окончания фактически выданных аренд, часовой пояс и состояние своего пула. Продление меняет календарь из данных заказа. Свободные и ожидающие подготовки аккаунты разделены: истечение времени само по себе не делает аккаунт готовым к выдаче. Возвраты исключены.

Итоги за сутки, неделю и 30 дней используют ту же методику подтверждённой выручки и расходов, что Excel. Доступны сравнение с предыдущим периодом, доля повторных покупателей, лидеры и часы активности. PNG содержит подтверждённую выручку по дням; данные для примеров не подмешиваются к магазину. Конверсия без просмотров не выдумывается. Неполные расходы и пересчёт USD помечают прибыль предварительной.

## Stars и SMM

Формы используют прежние проверенные адаптеры Split/SMM API v2. В Stars доступны пакеты 50/100/250/500/1000 и собственное количество. Для SMM предлагаются количества в диапазоне выбранной услуги. Каталог, цена, получатель, лимиты и подтверждение перед закупкой сохраняются. Частичное выполнение и остаток показываются существующей карточкой внешнего заказа. Неподдерживаемые отмена/refill и автоматический перенос спорной покупки к другому поставщику не добавлены.

## KOSell: RUB и USD

Баланс показывается раздельно. USD сохраняется с точностью до четырёх знаков. «Инструменты → Кошельки KOSell» позволяет выбрать валюту новых операций. После обновления прежний режим RUB сохраняется; если деньги лежат в USD, выберите «Оплачивать USD» один раз. Ключ повторно вводить не требуется.

Кошельки не складываются, обмен валют не выполняется. Каталог доступности, расчёт заказа, закупка и продление проверяют именно выбранный кошелёк. Лимит закупки остаётся в RUB по котировке KOSell. Отправленная аренда хранит валюту в своём запросе и использует прежний ключ при восстановлении; изменение настройки не меняет этот запрос. Неопределённое продление не повторяется.

Нативная сумма фактического списания сохраняется в отдельном журнале. Для USD рублёвый эквивалент рассчитывается по соотношению RUB/USD из котировки перед операцией и считается оценочным. Это не независимое подтверждение точного рублёвого расхода и не скрытая конвертация кошелька. При неполных финансовых данных сохраняется ID операции поставщика, заказ передаётся на сверку до выдачи реквизитов.
