# Аудит PlayerokHelper 0.6.2

28 ноября 2026 года.

## Объём

Проверен весь существующий набор тестов и добавлен обход Telegram-панели через настоящий Dispatcher aiogram с подменённой сессией Telegram и API поставщиков. На заполненном тестовом магазине обнаружены 279 уникальных действий; автоматически открыты 263 экрана, формы и переключателя. Отдельно открыты основные разделы чистой установки. [Инвентарь кнопок](qa/v0.6.2-buttons.txt): OPEN — обработано обходом; TRANSACTION/CONTEXT — действие проверяется в отдельном сценарии с необходимым состоянием.

Действия с ID и токенами в инвентаре — тестовые примеры. Список не означает живую приёмку на сервере продавца или проверку каждого варианта ответа внешнего сервиса.

Локальный итог: **420 тестов прошли**, Ruff и форматирование пройдены, shell-сценарии проверены. Перед публикацией также проверяются сборка/установка wheel и GitHub CI на Python 3.11/3.12.

## Исправленные дефекты

1. Возврат больше не сравнивает статус подключения с устаревшим значением «готово»: перед запросом используется реальный профиль Playerok. KOSell для возврата не требуется. Запрос с потерянным ответом не отправляется второй раз.
2. Переключение ежедневного отчёта, паузы, платных действий и режима вне сети сохраняет текущий экран настроек.
3. Кнопка «Назад» из первого поля восстанавливает исходный раздел. Устаревшая или удалённая кнопка не оставляет пользователя без ответа.
4. Обновление баланса поставщика не затирает собственный результат следующим экраном; добавлены индикатор загрузки и таймаут. Запуск сам загружает устаревшие сведения о подключении.
5. Stars/SMM используют каталог собственных товаров с автоматическим названием, сохраняя ввод обычной ссылки как запасной вариант.
6. Страницы заказов ограничены реальным количеством записей. Центр событий ведёт прямо к приостановленным/ошибочным заказам и проблемным операциям.
7. Пустой выбор для массового изменения объясняет, как выбрать товары; предпросмотр показывает русские поля и значения.
8. Внутренние причины остаются в базе и диагностике; сообщения показывают понятную причину и следующий шаг. Нет косметического перевода ошибочных или частичных заказов в успешные.

## Границы проверки

Реальные покупки, возвраты, отправки покупателям и развёртывание на VPS не выполнялись. Тесты используют подменённые API. Доступность Playerok с конкретного VPS, действительность ключей, баланс и результат услуги зависят от внешних площадок. Ошибки этих сервисов сохраняют свой реальный статус и не скрываются оформлением.

Схема базы, служба, updater_worker.py и протокол помощника 1 не менялись. Переход на общий бот не выполнялся.
