# Навигация PlayerokHelper

Структура с версии 0.6.3. Главное меню — вертикальный список. До подключения аккаунта над ним отображается кнопка добавления Playerok.

| Раздел | Что внутри |
| --- | --- |
| ⭐ Автонастройки | Сообщения покупателям, автоответчик, режим работы, продвижение, уведомления, область настроек |
| 📦 Мои лоты | Каталог, добавление, поиск, массовые настройки, шаблоны лотов; цена и выдача в карточке лота |
| 👤 Профиль | Аккаунт и балансы, чаты, все заказы, покупатели, центр событий |
| 📈 Аналитика | Сводка, графики, Excel, товары и период; ежедневный отчёт и комиссия в настройках отчёта |
| ⚡ Плагины | KOSell и валюта, собственная аренда с календарём, Telegram Stars, SMM, бонусные товары |
| ⚙️ Управление магазином | Подключения, статус, пауза, обновления, резервная копия |
| 📞 Поддержка | Документация и обращение на GitHub |

## Сообщения и автоответы

В «Сообщениях покупателям» выбирается событие. Его карточка содержит состояние, текущий текст, включение/выключение и редактирование. Переключение остаётся в этой карточке. Автоподтверждение выполнения имеет собственную карточку без редактора текста.

В «Автоответчике» находятся ответы по ключевым словам, сценарии с условиями и заготовки быстрых ответов. В «Режиме работы» — часы магазина и ручной режим вне сети.

## Назад и отмена

- В обычном разделе — одна синяя кнопка «Назад». Она ведёт в родительский раздел.
- В форме — один нижний ряд «Назад / Отменить». Назад восстанавливает предыдущий шаг; отмена закрывает ввод и открывает исходный раздел.
- После сохранения обычной настройки открывается её карточка, без промежуточного пустого окна «Сохранено».
- После перезапуска незавершённый ввод не возобновляется автоматически; кнопки возвращают в родительский раздел. Для подключения потребуется начать форму снова.
- ID текущей текстовой панели и безопасные имена разделов сохраняются в настройках. Реквизиты, код входа, токен и текст формы в эти метаданные не записываются.
- Старое меню не подменяет более новую панель после уведомления. Уведомления и файлы сохраняются отдельными сообщениями.
- Повторяющиеся callback и URL на одном экране удаляются. Цвет кнопок использует поддержку Telegram-клиента.

Старые кнопки и команды поддерживаются для совместимости. Старый общий экран инструментов открывает главное меню; его функции размещены в соответствующих разделах.
